# WebTranslate 产品方案

## 1. 产品定位

WebTranslate 是一个基于浏览器的选中内容翻译插件。用户在网页中选中一大段内容后，插件自动识别其中的段落，调用用户配置的大模型逐段翻译，并将每段译文插入对应原文块下方。

第一阶段不做整页扫描，只处理用户主动选中的内容。

## 2. 核心流程

1. 用户选中一大段网页文本。
2. 插件识别选区中的段落、标题和列表项。
3. 插件展示段落数量、字符数和开始翻译按钮。
4. 插件按批次调用用户配置的大模型。
5. 每段译文直接插入对应原文块下方，并展示段落级翻译状态。
6. 用户可以取消当前翻译任务；失败段落显示具体错误。

## 3. MVP 功能

- 选中文字后显示翻译按钮。
- 支持一次选中较长内容并拆分为多个段落。
- 支持 OpenAI 兼容接口。
- 支持自定义 API 地址、API Key、模型名称和目标语言。
- 支持段落级翻译状态、失败重试和取消。
- 支持复制全部译文。
- 译文使用插件创建的独立 DOM 节点插入原文块下方，不改写原文文本。

## 4. 后续功能

- 段落级重试和译文复制。
- 术语表和翻译风格模板。
- Ollama、本地模型和多模型 fallback。
- 翻译缓存和长任务恢复。
- Chrome 右键菜单与快捷键。

## 5. 技术架构

```text
Content Script
  ├── 读取选区
  ├── 段落拆分
  ├── 显示选区翻译按钮
  ├── 识别选区对应的网页块元素
  └── 将译文插入每个原文块下方
  └── 管理段落级状态

Service Worker
  ├── 读取本地模型配置
  ├── 调用 OpenAI 兼容 API
  ├── 控制批次和超时
  └── 返回结构化译文

Popup
  └── 配置 API 地址、模型、密钥和目标语言
```

## 6. 设计边界

- 只翻译当前选中的文本，不主动扫描整页。
- 输入框、密码框和可编辑区域默认不触发翻译按钮。
- 选区过长时自动分批，避免超过模型上下文限制。
- API Key 只保存在浏览器扩展本地存储中，不写入网页 DOM 或 URL。
- 第一版按纯文本段落处理，保留段落顺序和换行；HTML 标签保留属于后续增强功能。
