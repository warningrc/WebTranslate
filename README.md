# WebTranslate

WebTranslate 是一款基于浏览器的网页选中翻译扩展。选中网页中的一段或多段内容后，可调用自己配置的大模型进行翻译，并将译文直接放在对应原文下方，适合阅读外文网页、查阅资料和语言学习。

## 产品设计

- **只翻译主动选中的内容**：不会扫描或翻译整页。选区跨越多个段落时，按网页中的段落、标题和列表结构拆分；若只选中某个内容块的一部分，只发送选中的文字。
- **翻译入口贴合阅读场景**：可使用选区旁的快捷按钮，也可使用右键菜单中的“翻译为{目标语言}”快捷项，或从“翻译为”子菜单临时选择其他语言；当选区已是默认目标语言时，快捷项会隐藏。
- **译文与原文逐段对应**：译文直接插入相应原文下方，不使用弹窗遮挡页面。每段译文都可单独关闭；失败时显示错误信息，并支持单段重试。
- **翻译状态清晰但克制**：开始翻译后，所有选中段落末尾立即显示小型旋转提示，包括排队等待的段落。收到结果后，提示消失并显示译文。
- **上下文只辅助理解**：可在管理页开关上下文辅助。开启后会把选区内相邻段落作为参考，但只翻译当前段落，不重复输出上下文。
- **自动识别原文语言**：模型逐段判断原文语言，再翻译为指定目标语言；不要求用户预先选择源语言。

## 翻译与模型配置

管理页可配置 OpenAI Chat Completions 兼容的大模型服务，包括 API 基础地址、API Key、模型和默认目标语言。模型名称支持从服务端获取列表，也可手动填写。

目标语言包含简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español 等主流语言。翻译风格提供自然表达、忠实准确、技术文档、学术严谨、商务专业和轻松口语等预设；用户可以编辑风格要求，自由调整措辞、语气和术语规则。

## 缓存与页面控制

- 翻译结果缓存在扩展本地，最多保留 1000 条，90 天后过期；缓存按原文、目标语言、模型、风格和相关上下文区分，重复翻译可复用结果。
- 扩展弹窗提供“清除本次译文”，可清空当前页面由扩展插入的译文，同时保留各段的关闭按钮；原文不会被修改。
- 管理页可清空全部本地翻译缓存。

## 数据与隐私

API Key 和偏好设置保存在当前浏览器的扩展本地存储中。只有用户主动选中的文字、必要的上下文和翻译配置会发送到用户设置的模型服务；WebTranslate 不提供中转翻译服务器。请根据所使用模型服务的隐私政策评估发送内容。

## 使用方式

1. 在扩展管理页配置模型服务、API Key、模型和默认目标语言，并保存设置。
2. 在网页中选中需要翻译的文本。
3. 点击选区旁的翻译按钮，或右键使用默认目标语言快捷项；也可以从“翻译为”子菜单选择其他语言。
4. 译文会逐段显示在原文下方，可按段关闭、对失败段落重试，或从扩展弹窗清除本页译文。
