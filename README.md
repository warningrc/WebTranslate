# WebTranslate

基于浏览器的选中段落翻译插件。用户选中一大段网页内容后，插件按段落拆分，并通过用户配置的 OpenAI 兼容大模型逐批翻译。

## 当前状态

已完成第一版代码骨架：

- Manifest V3 扩展结构
- 选区读取和浮动翻译按钮
- 根据网页段落、标题和列表项识别选区内容
- 每 5 段一批调用模型
- 取消当前翻译任务
- 每个译文插入对应原文块下方
- 翻译结果本地缓存（最多 1000 条，90 天过期）
- API 基础地址、Key、模型列表选择、目标语言和风格配置

## 本地加载

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本项目的 `code/` 目录。
5. 点击扩展图标，打开管理页面，填写模型配置并保存。
6. 在普通网页中选中一大段文本，点击“翻译选中内容”。

当前版本使用纯原生 JavaScript，无需 `npm install` 或构建步骤。

## 当前限制

- 翻译结果插入选区对应的原文块下方；选区只覆盖块内部分内容时，仅发送选中的文本。
- 已翻译内容按原文、目标语言、模型和风格保存在扩展本地缓存中；管理页可清空缓存。
- 目前默认使用 OpenAI Chat Completions 兼容格式。
- 接口地址填写 API 基础地址（例如 `https://api.openai.com/v1`），插件自动补全接口路径；模型列表通过兼容服务的 `/models` 接口获取，不支持枚举的服务可手动填写模型名。
- 对没有明确块级结构的特殊网页，选区可能会作为单个段落处理。
- 尚未实现段落级重试按钮、右键菜单和快捷键。
